    Automation

    不用看盤的自動交易方式

    GitHub Pages 這個前端網站只負責分析與產生參數；真正自動下單必須放在安全後端，不能把 OKX API Key 寫在網頁裡。

    目前安全版網站挑 Top 3 → 複製參數 → 你到 OKX 手動確認。
    半自動版Cloudflare Worker 定時掃描 → Telegram/Line 通知你 → 你手動下單。
    全自動版Cloudflare Worker / VPS 儲存 API Key → 依策略自動下單、止盈、止損。新手不建議直接用真錢。

    重要：API Key 只能放後端或本機機器人，權限只開 Read + Trade，不開 Withdraw，最好綁定固定 IP、使用 OKX 子帳戶與小額資金。
