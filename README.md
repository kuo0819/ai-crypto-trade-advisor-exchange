# AI OKX 下單參數助手

這是 OKX 新手交易輔助網站，設計重點是「下單填表模式」：先判斷能不能做，再直接把 OKX 合約 / 現貨欄位要填的參數列出來。

## 功能

- OKX 專用公開行情資料，不需要 API Key
- 合約與現貨分開顯示
- 合約顯示：交易對、開倉、逐倉、開多/開空、槓桿、限價價格、數量、止盈、止損
- 現貨顯示：交易對、買入/不買、限價價格、買入金額、止損參考、分批賣出價格
- 顯示這筆交易如果止損，預估最多虧多少 USDT
- 支援主流幣掃描
- 適合 GitHub Pages 靜態部署

## 新手預設

- 市場：OKX USDT 永續合約
- K 線週期：4H
- 單筆風險：1%
- 槓桿：2x
- 委託方式：限價委託
- 合約倉位模式：逐倉

## GitHub Pages 部署

1. 建立 GitHub repository。
2. 把本資料夾內所有檔案上傳到 repository 根目錄。
3. 到 `Settings` → `Pages`。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`。
6. 儲存後等待 GitHub 產生網址。

## 風險提醒

這是技術分析輔助工具，不是投資建議，也不能保證獲利。合約與槓桿會放大虧損。任何交易都必須先設定止損，且單筆風險不要超過自己能承受的範圍。
